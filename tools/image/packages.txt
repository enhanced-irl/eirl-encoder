# tools/image/packages.txt — what the image installs on top of ubuntu-base 18.04.5, with
# apt-get install --no-install-recommends (IMAGE.md §3.2). One package per line, a comment after it.
# It is base/keep.txt (BASE.md §3) without the development group (D4), without what only the retired Python
# engine used (python3-gi, python3-cairo, gir1.2-*) and without bluez (D-I6), plus what ubuntu-base lacks and
# the Ubuntu dependencies of the NVIDIA packages (their dpkg -i needs them already installed).
# The exact result, with versions, is tools/image/packages.lock.
