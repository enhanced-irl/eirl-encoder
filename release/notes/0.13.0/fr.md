- Nouveau : si vous oubliez le mot de passe de l'interface web, définissez-en un nouveau avec le code de configuration. Sur le web, « Mot de passe oublié ? » à la connexion ; le code s'affiche sur l'écran, dans Réglages › Appareil › Nom et mot de passe, derrière l'œil. Depuis l'écran, vous pouvez aussi en définir un nouveau sans le code. Le changer ferme toutes les sessions web.
- Plus sûr : l'interface web demande son mot de passe pour associer l'encodeur à EnhancedIRL et pour le dissocier, et les tentatives ratées d'une autre personne sur votre réseau ne vous bloquent plus si vous vous étiez déjà connecté.
- Plus sûr : le fichier du mot de passe web n'est lisible que par l'application de l'encodeur, et un compte EnhancedIRL ne peut mettre que ses relais comme destination.
